# 🧪 Počítačová chemie | Přírodovědecká fakulta Univerzity Palackého v Olomouci

Oficiální webová prezentace, interaktivní učebnice a studijní materiály nového bakalářského studijního programu **Počítačová chemie** na Přírodovědecké fakultě Univerzity Palackého v Olomouci (Katedra fyzikální chemie).

---

## 🌟 O studijním programu

- **Typ studia:** Bakalářské (Bc., 3 roky), prezenční
- **Navazující studium:** Magisterské (Mgr., 2 roky) – studijní program *Fyzikální chemie* se zaměřením na výpočetní metody a modelování
- **Garantka programu:** Mgr. Marie Zgarbová, Ph.D.
- **Klíčový pedagog & koordinátor:** prof. RNDr. Karel Berka, Ph.D.
- **Katedra:** Katedra fyzikální chemie PřF UP v Olomouci (kampus Envelopa, 17. listopadu 1192/12)

---

## 🚀 Klíčové součásti webu

1. **Hlavní web ([`index.html`](index.html))**
   - Vizuální styl UPOL, 3 pilíře (Chemie + IT/AI + Fyzika/Matematika), uplatnění absolventů, medailonky vyučujících a akreditovaný studijní plán.
2. **Interaktivní učebnice a online simulace ([`ucebnice.html`](ucebnice.html))**
   - 10 kapitol pro středoškoláky a uchazeče o studium.
   - Interaktivní simulátory přímo v prohlížeči:
     - ⚡ *Trojúhelník kompromisů* (výpočetní metody QM, MD, CG, Bod D / AI)
     - ⚡ *Vazba H₂ a Morseův potenciál* (propojeno s [3D Orbital Simulator](https://karelberka.github.io/orbital-simulator/))
     - ⚡ *Vibrační pohyby a IR spektroskopie* (animované molekuly $H_2O$ a $CO_2$)
     - ⚡ *Simulátor dokování léčiv* (usazení ligandu do vazebné kapsy enzymu)
     - ⚡ *AlphaFold & Mol\* 3D Protein Explorer* (Nobelova cena za chemii 2024)
3. **Informační leták ([`letak.html`](letak.html) & [`assets/docs/letak-pocitacova-chemie-upol.pdf`](assets/docs/letak-pocitacova-chemie-upol.pdf))**
   - Přehledný formátovaný propagační leták připravený k tisku a distribuci pro střední školy.

## 💻 Spuštění webu lokálně

Web je navržen jako moderní statická webová aplikace bez nutnosti instalace databází.

```bash
# Spuštění lokálního webového serveru v Pythonu
python -m http.server 8000
```
Poté otevřete v prohlížeči `http://localhost:8000`.
